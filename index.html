How ONIONIQ Works

A transparent look at the AI-assisted grading workflow, from capture to digital report.

  1. 01

    Capture

    Capture or upload the onion batch image using a device camera or file upload.

  2. 02

    Detect

    Computer vision identifies individual onions within the batch image and draws bounding boxes.

  3. 03

    Analyze

    The system evaluates appearance, damage, rot, sprouting, and size for every detected onion.

  4. 04

    Grade

    Measurements are processed through rule-based grading logic to estimate Grade A and URS percentages.

  5. 05

    Report

    A digital quality report is generated instantly, ready to save, print, or share.

About Demo Mode

ONIONIQ runs a client-side AI vision simulation entirely in your browser. It uses real image processing (brightness, pixel statistics, dimension analysis) via the Canvas API to seed a deterministic simulated detection and grading pipeline — no backend, no external AI API, and no data leaves your device.
